# Kleinagent-UI

Weboberfläche für den privaten Kleinanzeigen-Agenten: Watchlist pflegen, letzte Treffer ansehen, Suche starten.

**Seite:** <https://skiingd.github.io/Kleinagent-UI/>

Dieses Repo ist öffentlich und enthält **nur den Seitencode** – keine Watchlist, keine Treffer, keine Tokens.
Die Daten liegen im privaten Repo und werden im Browser über die GitHub-API gelesen/geschrieben.
Den nötigen Fine-grained Token gibst du einmal auf der Seite ein; er wird nur im Browser gespeichert
(Anleitung im README des privaten Repos).

Dateien: `index.html`, `app.js`, `app.css`; `js-yaml.min.js` (js-yaml 4.1.0, MIT-Lizenz, siehe `js-yaml.LICENSE`).
